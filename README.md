# MySuperAssistant

Личный ассистент для ПК и смартфона на C++20 и Qt6. Репозиторий содержит каркас
трёх приложений: сервера, Windows-клиента и Android-клиента.

Сейчас работают только библиотечные части: локальный разбор русских команд,
типы планировщика, интерфейсы часов и репозиториев и сервисы напоминаний по времени, календаря дня/месяца, привычек, задач и ежедневного приветствия. Для тестов есть часы
и репозитории в памяти. Остальная логика планировщика, хранение на диске, сеть, чат,
музыка, ментор и геймификация ещё не реализованы.

`msa_server` сразу завершается с кодом 0. `msa_desktop` и `msa_mobile`
создают `QGuiApplication` и запускают цикл событий, но не создают окна и не загружают QML.
Это пока не приложения, которыми можно пользоваться как ассистентом.

## Сборка Windows Debug

Требуются CMake 3.25 или новее, Visual Studio 2022 с компилятором MSVC для x64,
Git для загрузки зависимостей и Qt 6.10 или новее с компонентами Gui и Quick.
В шаблоне личных пресетов указан Qt 6.10.2: `C:/Qt/6.10.2/msvc2022_64`.

1. Если `CMakeUserPresets.json` ещё нет, создайте его из шаблона в корне репозитория:

   ```powershell
   Copy-Item CMakeUserPresets.json.example CMakeUserPresets.json
   ```

   При необходимости исправьте `CMAKE_PREFIX_PATH`. Личные пути хранятся в этом файле.

2. Из корня проекта выполните:

   ```powershell
   cmake --preset windows-debug-local
   cmake --build --preset windows-debug-local
   ctest --test-dir out/build/windows-debug-local -C Debug --output-on-failure
   ```

   Результат — Debug-сборка в `out/build/windows-debug-local` и успешный прогон тестов.
   Первая конфигурация загружает PCRE2 10.47 и GoogleTest v1.18.0 с GitHub через
   `FetchContent`, поэтому требует доступа к сети. Visual Studio — многоконфигурационный
   генератор: Debug задаётся build-пресетом, а для CTest — параметром `-C Debug`.

Тесты собраны в `msa_core_tests` и регистрируются через `gtest_discover_tests`:
разбор команд, временные границы, типы планировщика, контракты репозиториев и фейковые часы.
Исходники находятся в `tests/core/`.

Ветка сборки Android есть в CMake, но Android-пресетов в репозитории пока нет;
инструкции сборки и установки мобильного приложения ещё не подготовлены.
