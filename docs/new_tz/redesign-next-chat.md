## Реализовано

- H1: типы, проверки, явные наблюдения таймера/три варианта отсутствия,
  снимки плана/факта, пропуски/замены, завершение/исправление и проекция прогресса.
  core не зависит от Qt/файлов/сети. ID и наблюдения времени передаёт вызывающий код.
- H2: SqliteSportStore, строгий SportDocumentCodec, три core-порта с дисковой
  и тестовой реализациями. Схема 3, application_id/marker, чтение идентичности
  до записи, проверенная VACUUM INTO-копия перед миграцией, транзакции/CAS.
  Есть checkpoint занятия и неполного редактора программы; ошибки не стирают ввод.
- SportCatalog читает встроенный пакет 22 идентичностей. **Опубликовано 6 карточек**:
  03/05/06/07/11/12. Источники ACE/NASM проверены 2026-11-24; остальные 16
  не выдаются за готовые. Новое содержимое существующей карточки — новая редакция.
- SportLibraryModel/SportController и SportLibraryPanel: поиск, фильтры,
  краткая/полная техника, альтернативы, независимые сохранённые предпочтения.
  При ошибке базы встроенные карточки остаются читаемыми; подтверждение отметки
  только после успешной записи. TCP не участвует.
- Main обоих клиентов задаёт AppLocalDataLocation/sport/sport-local.sqlite;
  --sport-data задаёт изолированный путь. Runtime без пути — каталог без записи,
  тесты задают QTemporaryDir. Настройки сервера не очищают спортивные данные.
