## Разрешение и границы

Решение 75 разрешает автономное завершение согласованного MVP и исправление
регрессий без повторных технических согласований. Не менять сервер, серверную
SQLite, TCP, Ламу и архитектуру синхронизации. Перенос приостановлен. Не читать
старый проект без названного файла. Без новых зависимостей и commit/push.
Не удалять пользовательские данные и не мигрировать реальные базы без отдельного
согласия; миграционные/аварийные тесты используют только QTemporaryDir.

## Реализовано

- H1/H2 и локальный сценарий программ/занятия/истории/динамики сохранены.
  core — stdlib, infra — Qt SQL/кодеки, apps — связывание, UI — модели/формы.
- 22/22 карточки опубликованы в новых неизменяемых редакциях с первичными
  источниками. Краткая/полная техника, условия, ошибки, ограничения и учёт.
- P1/P3 A/B: состав, описание, оборудование, условия и альтернативы. Копия
  собственной программы имеет новые ID и пустые подходы. Пользователь заполняет
  дозировку сам; индивидуальные веса/автопрогрессия не назначаются. P1 не считается
  автоматически безопасной при боли. Точные готовые дозировки не утверждены.
- Отдельные active/result editor: просмотр и исправление другого результата
  не останавливают занятие. Незавершённая правка сохраняется в SQLite с сырым
  вводом, восстанавливается после запуска и явно отменяется с подтверждением.
  Прогресс строится только по текущим завершённым редакциям, не по черновикам.
- Схема 5: correction_drafts с UUID редактирования, последовательностью и
  неизменным baseline. CAS защищает от повторов, ABA и потери чужого черновика.
  Завершение исправления атомарно меняет голову и снимает только свой черновик.
- Старую базу до явного согласия на «Обновить с копией» открывают только для
  проверки чтением. После согласия — проверенный VACUUM INTO и транзакция.
  Смена серверных настроек не очищает спортивную базу.
- Реальные переходы к полной карточке и обратно сохраняют исходный экран.
  Числовые поля передают IME-подсказки; количество гантелей варианта явно задано.
- Таймер активного занятия независим от редактора результата. Восстановление
  интервала: активность / пауза / активная часть вручную; исходные отметки
  сохраняются, повторный учёт запрещён. Ошибки записи не скрываются.

## Проверки и продолжение

Актуальные результаты Windows/Android, пути APK и снимков — в разделе 17
sport-2a-draft.md и README. Offscreen использует настоящие оболочки на тестовых
данных, а не подключённый телефон. При наличии A55 проверить IME, системный
Назад, фон/завершение процесса, восстановление и реальное исполнение QSQLITE.
Историческая проверка 1A–1C на A55 не подтверждает новый спортивный сценарий.
Не терять manifest adjustResize, не запускать личный сервер/Ламу/VPN ради проверки.

Для использования заготовок пользователь заполняет подходы/повторы/вес сам.
Готовые предустановленные дозировки требуют отдельного содержательного решения;
они не блокируют запись своих занятий. Синхронизация остаётся будущим отдельным
проектированием. Проверки на реальной пользовательской базе агент не проводил.
