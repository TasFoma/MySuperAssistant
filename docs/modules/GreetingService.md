# GreetingService

Ежедневное приветствие реализовано в `src/core/include/msa/core/GreetingService.h`
и `src/core/src/GreetingService.cpp`. Интерфейс хранения даты — `GreetingRepository.h`
в том же каталоге заголовков; деструктор — в `src/core/src/GreetingRepository.cpp`.
Все зависимости передаются невладеющими ссылками через конструктор. API — в Doxygen.

## Работа

`greetingIfNeeded` один раз считывает местное время из `Clock` и проверяет дату
в `GreetingRepository`. Если она совпадает с сегодняшней, возвращает `nullopt`.
Иначе формирует текст: до 08:00 «Доброй ночи», до 12:00 «Доброе утро»,
до 18:00 «Добрый день», затем «Добрый вечер».

Далее идут русская дата с днём недели, события на сегодня из `CalendarService`
(включая повторения) и до пяти незавершённых задач из `TaskRepository`.
Задачи сортируются по убыванию приоритета, затем по сроку (отсутствующий — после
датированных), затем по ID. Отбираются открытые задачи независимо от срока.
События с временем показываются как `HH:MM — название`, без времени — названием.
Формат русской даты и времени общий со сводкой DailyContextService и реализован
во внутреннем `src/core/src/PlannerText.*`.
При отсутствии событий и открытых задач добавляется предложение запланировать день.

Дата сохраняется после формирования текста и до его возврата. Ошибки зависимостей
пробрасываются исключениями. Реализация в памяти `tests/core/InMemoryGreetingRepository.*`
сохраняет дату между экземплярами сервиса, если используется тот же объект хранилища.
[SqliteGreetingRepository](SqliteGreetingRepository.md) сохраняет дату в файле SQLite
между открытиями базы; схема версии 4. Приложения пока не используют репозиторий.

## Ограничения

Нет таймера и доставки сообщения, сервис пока не подключён к приложениям.
Сохранённая дата означает подготовленное приветствие, а не подтверждённую доставку:
сбой после сохранения может привести к пропуску сообщения. Параллельные вызовы
не синхронизируются. Сравнивается только последняя дата: перевод часов на другую
дату может вызвать новое приветствие. Просроченные приветствия не воспроизводятся.
Вечерний опрос настроения, контекст LLM и память профиля сюда не входят.

## Тесты

`tests/core/src/GreetingServiceTest.cpp` проверяет границы суток, русскую дату, пустые
планы, повторный вызов и пересоздание сервиса с тем же хранилищем, новый день,
события с повторениями, сортировку и предел задач, а также ошибку сохранения даты.
Сборка и тесты — в [README](../../README.md).
