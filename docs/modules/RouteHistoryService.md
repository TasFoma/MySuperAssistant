# История расчётов маршрутов

RouteHistoryService и RouteHistoryRepository находятся в `core`, SQLite-реализация
SqliteRouteHistoryRepository — в `infra`. Поведение согласовано решением 43.
Заголовки — `src/core/include/msa/core/RouteHistoryService.h`,
`RouteHistoryRepository.h`, `src/infra/include/msa/infra/SqliteRouteHistoryRepository.h`;
реализации с теми же именами — в соответствующих каталогах `src/`.

## Точки входа и работа

- `RouteHistoryService::record` проверяет полный RouteCalculation, назначает
  местное время из Clock и сохраняет через репозиторий. Неверный ввод —
  invalid_argument, техническая ошибка записи — исключение без успешного результата.
- `recent` возвращает последние пять по ID от новых к старым; перевод часов
  не меняет порядок. Все старые записи сохраняются.
- `statistics` считает число/суммы метров и прогнозных секунд маршрутизатора;
  приблизительные оценки учитываются отдельным числом. Переполнение сумм — ошибка.

NavigationService получает обязательный RouteHistoryService через конструктор.
После успешного маршрута или приблизительной оценки он сохраняет исходные
названия, фактические координаты, режим и прогнозные метры/секунды до возврата.
Для старта по координатам название — «Моё местоположение». Неудачный поиск,
отказ по расстоянию и неверный ответ маршрутизатора не создают историю.
Каждый новый вызов с успешным расчётом создаёт отдельную запись, без дедупликации.

История описывает построения, а не совершённые поездки. Пройденные километры,
измеренная скорость и персонализация по прогнозам не вычисляются.
Сеть выполняется до записи и вне транзакции. При ошибке хранилища маршрут
не возвращается как успешная операция; автоматического повтора нет.

## SQLite

Миграция 12 добавляет `route_calculations`: постоянный AUTOINCREMENT ID, местные
секунды created_at, полные названия, четыре координаты, режим, метры, секунды
и approximate. Параметры привязываются; Unicode, пробелы и переносы сохраняются.
Проверяются конечность/диапазоны чисел и режим. SQL-ошибки/повреждение — runtime_error.
Одна вставка участвует во внешней транзакции общего SqliteDatabase.
Автоматической очистки и удаления истории через сервис пока нет.
