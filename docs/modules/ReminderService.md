# ReminderService

Сервис предметной логики напоминаний по времени и месту: `msa::core::ReminderService`.
Заголовок — `src/core/include/msa/core/ReminderService.h`, реализация —
`src/core/src/ReminderService.cpp`, тесты — `tests/core/ReminderServiceTest.cpp`.
Зависимости `Clock` и `ReminderRepository` передаются по ссылкам через конструктор.
Они должны жить дольше сервиса. API описан в Doxygen заголовка.

## Операции

- `activeReminders`: возвращает независимые копии однократных и геонапоминаний
  Pending и всех повторяющихся. Сначала общая группа по возрастанию dueAt,
  затем геонапоминания, включая записи без координат; при равенстве — по ID.
  Чтение не запускает обработку просроченных записей, не меняет статусы и сроки.
  Fired/Missed исключаются, ошибки репозитория пробрасываются (решение 30).
- `addTimed`: сохраняет однократное напоминание в статусе `Pending`. Момент строго
  раньше текущего отклоняется с причиной и просьбой выбрать другое время; равный текущему допустим.
- `addRecurring`: первый запуск через заданный интервал от текущего времени.
  Нулевой, отрицательный или непредставимый интервал отклоняется без сохранения.
- `skipMissedOnStartup`: после загрузки хранилища, перед первой проверкой, вызывающая
  сторона помечает прошлые однократные записи `Pending` как `Missed`. Уведомлений нет.
  Равные текущему времени, будущие, уже показанные и повторяющиеся записи не меняются.
- `checkDue`: для записей со сроком не позже текущего времени переводит однократные
  из `Pending` в `Fired`; повторяющиеся переносит на сейчас плюс интервал.
  Пропущенные интервалы не воспроизводятся. Возвращает исходные записи для уведомления,
  только после успешного обновления каждой записи. Порядок не гарантируется.

- `addPlace`: сохраняет геонапоминание Pending. Название и место содержат минимум
  одну кодовую точку, текст сохраняется без обрезки пробелов. Координаты необязательны;
  без них запись не срабатывает. Проверяются конечность чисел и диапазоны широты
  −90…90 и долготы −180…180, включая границы и нули.
- `checkNearPlace`: принимает текущую позицию, проверяет Pending с координатами,
  при расстоянии строго меньше 200 м сохраняет Fired и возвращает исходные записи.
  Считает расстояние по сфере радиусом 6 371 000 м формулой гаверсинусов, включая
  переход через ±180°. Результат PlaceCheckResult — список PlaceReminder либо
  ReminderRejection при неверной текущей позиции, без изменения хранилища.
  Порядок не гарантируется; уже Fired/Missed не выдаются. Неверные сохранённые
  координаты ожидающей записи вызывают std::runtime_error.

`ReminderCreationResult` содержит ID либо `ReminderRejection` с текстом причины.
Технические ошибки хранилища пробрасываются исключениями. Исчезновение записи при
обновлении и некорректный сохранённый интервал вызывают `std::runtime_error`.

## Ограничения

Сервис не подключён к приложениям. Таймер, запуск восстановления и доставка уведомлений —
обязанности вызывающей стороны; автоматического запуска в конструкторе нет.
Работа предполагает последовательные вызовы без конкурентного изменения репозитория.
Обновления нескольких записей не образуют транзакцию: при ошибке часть уже может быть
обновлена. Гарантии доставки уведомлений при сбоях пока нет.

Получения геолокации и геокодинга нет. Проверка текста применяется только к addPlace;
календарь и напоминания о событиях не входят в этот сервис. Флаг `fired` у однократных и геонапоминаний заменён статусом
`Pending/Fired/Missed`; повторяющиеся по-прежнему хранят следующий срок и интервал.

Тесты проверяют отказы без сохранения, точный срок, однократность, восстановление после
остановки, несколько пропущенных интервалов, сохранение будущих и геозаписей,
а также ошибку некорректного интервала в хранилище. Сборка и запуск — в [README](../../README.md).
Тесты списка проверяют пустой результат, исключение Fired/Missed обоих однократных
видов, общий порядок временных записей и порядок по ID, геозаписи без координат,
независимость копий, отсутствие обработки при чтении и список после срабатывания и удаления.

`tests/core/PlaceReminderTest.cpp` проверяет создание с координатами и без них,
односимвольные названия, неверные числа и диапазоны, точки внутри и снаружи радиуса,
однократность, сохранение остальных записей, экватор, полюс и переход через ±180°,
а также повреждённые координаты в хранилище. Геопроверка имеет те же ограничения
частичных обновлений и доставки при сбое, что и checkDue; точность GPS не учитывается.
