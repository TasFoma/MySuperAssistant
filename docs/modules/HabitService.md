# HabitService

`msa::core::HabitService` создаёт привычки, записывает прогресс и возвращает текущие
суммы. Зависимости `Clock` и `HabitRepository` передаются невладеющими ссылками.
Заголовок — `src/core/include/msa/core/HabitService.h`, реализация —
`src/core/src/HabitService.cpp`. API описан в Doxygen заголовка.

## Операции

`addHabit` сохраняет название, цель, единицу и период. Цель — положительное конечное
число; период — `Day` или `Week`. `logHabit` добавляет положительное конечное значение
за местный сегодняшний день сервера. Отсутствующая привычка возвращается как отказ.
Результат записи — ID либо `HabitRejection` с причиной. Неверный ввод не сохраняется.

`habits` возвращает копии привычек по ID с вычисленным прогрессом. Для дневного
периода учитываются только записи за сегодня; для недельного — с понедельника по
сегодня включительно. Дата считывается один раз на запрос. Будущие записи не входят
в сумму. Прогресс не ограничивается целью; журнал при смене периода не удаляется.

## Ограничения

Приложения пока не вызывают сервис. Нет UI, исправления отметок и записи задним числом,
проверки названий и единиц. Удаление и замена привычки остаются операциями репозитория.
Чтение вызывает `all`, затем `logs` для каждой привычки; общей транзакции нет.
Технические ошибки хранилища пробрасываются. Некорректные даты журнала пропускаются;
неположительные/неконечные значения внутри выбранного периода и переполнение суммы
вызывают `std::runtime_error`. Проверки сервиса не защищают от прямой записи через репозиторий.

## Тесты

`tests/core/HabitServiceTest.cpp`: неверные числа без сохранения, отсутствующая привычка,
дробные значения, превышение цели, смена дня и недели через границу года, исключение
будущих записей, независимость привычек и копий, переполнение суммы,
отказ для неизвестного периода без сохранения, пропуск неверных дат журнала
и отказ для неположительных/неконечных значений внутри текущего периода.
Команды сборки и тестов — в [README](../../README.md).
