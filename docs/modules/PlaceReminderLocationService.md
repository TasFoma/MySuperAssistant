# Выбор точки геонапоминания

PlaceReminderLocationService в `core` реализует поиск вариантов и явное
подтверждение точки по решению 43. Заголовок —
`src/core/include/msa/core/PlaceReminderLocationService.h`, реализация —
`src/core/src/PlaceReminderLocationService.cpp`.

## Точки входа

- `prepare(reminderIdentifier, reference)` ищет кандидатов для существующего
  PlaceReminder со статусом Pending и отсутствующими координатами. Reference
  передаётся явно, нули допустимы. Кандидаты сортируются по расстоянию по сфере;
  при равенстве остаётся порядок поставщика. Автоматической записи точки нет.
- `confirm(proposalIdentifier, candidateIndex)` закрепляет выбранного кандидата.
  Использует внутренний снимок; изменение возвращённой копии не подменяет адрес.
- `cancel` удаляет предложение без изменения напоминания.

Зависимости ReminderRepository и Geocoder передаются через конструктор.
Обычно Geocoder — CachedGeocoder поверх общего NominatimGeocoder. Сетевой поиск
вне транзакции. Повторный вход в prepare во время поиска отклоняется; использование
сервиса последовательное, в одном потоке, без конкурентных вызовов.

## Актуальность и сохранение

После поиска и перед подтверждением напоминание перечитывается. Проверяются
тип, ID, полный заголовок и место, Pending и отсутствие координат. Изменение,
удаление, завершение или уже назначенная точка требуют нового выбора.
Новая попытка prepare для того же ID отменяет прежнее предложение, даже если
новый поиск завершился ошибкой. Остальные предложения сохраняются.

ID предложения принадлежит живому экземпляру сервиса. Предложения не пишутся
в БД, при перезапуске нужно повторить выбор. Это внутренний контракт, а не
готовый протокол/токен авторизации. Успешное подтверждение удаляет предложение;
повторное подтверждение отклоняется. Ошибочный индекс ничего не записывает.

Confirm меняет только coordinates полной актуальной записи через один update.
Никакого фонового обхода и автоматического переназначения точек нет. После
подтверждения перемещение телефона и обновление кэша точку не меняют.
Ошибки ввода/устаревшее предложение — ExternalServiceError; ошибки хранилища
пробрасываются исключениями и не удаляют предложение, оставляя возможность
явного повтора после устранения ошибки. Проверки и update используются в одном
потоке без внешних вызовов между ними; согласования конкурентных писателей нет.

## Тесты и ограничения

`tests/core/NavigationPersistenceTest.cpp`: явный выбор, порядок кандидатов,
подмена копии, изменение во время поиска/перед подтверждением, отмена,
новая попытка, повтор, неверный индекс и восстановление после исключения.
`tests/infra/SqliteNavigationRepositoryTest.cpp`: отказ SQL update, явный повтор
и фиксированная точка после открытия файла заново. Схема reminders не меняется.

UI выбора адреса, протокол и вызовы приложений пока отсутствуют. Геонапоминания
по близости проверяет существующий ReminderService; этот сервис только назначает
точку после подтверждения и не выдаёт уведомления.
