# CalendarService

`msa::core::CalendarService` читает календарь через невладеющую ссылку на
`EventRepository`. Заголовок — `src/core/include/msa/core/CalendarService.h`,
реализация — `src/core/src/CalendarService.cpp`. API описан в Doxygen заголовка.

## Поведение

`eventsForDate` возвращает независимые копии событий выбранного дня. Первыми идут
события без времени, затем события по времени, при равном времени — по ID.
Дата в возвращённом `Event` остаётся исходной датой начала повторения.

Повторы не происходят раньше исходной даты. `None` означает только исходный день,
`Daily` — каждый день, `Weekly` — тот же день недели, `Monthly` — то же число
или последний день месяца, если числа нет. Перенос не изменяет исходную запись:
после 28/29 февраля событие от 31 января снова приходится на 31 марта.
Годовых повторений нет.

`eventDaysInMonth` возвращает уникальные числа месяца по возрастанию. Для каждого
дня проверяется наличие хотя бы одного события с теми же правилами повторения.
Обе операции читают список репозитория один раз на вызов. Неверные параметры даты
или месяца дают пустой список; записи с неверной исходной датой пропускаются,
как в старой логике. Технические исключения хранилища пробрасываются.

## Ограничения и тесты

Сервис не создаёт события, не проверяет их заголовки и время, не рассылает уведомления
и не подключён к приложениям. Месячный запрос перебирает дни месяца и события.

`tests/core/CalendarServiceTest.cpp` проверяет исходные даты, ежедневные и недельные
повторы через границу года, месячные повторы в коротких и високосных месяцах,
возврат к исходному числу, сортировку, копирование, уникальность дней,
неверные даты и пустое хранилище. Сборка и тесты — в [README](../../README.md).
