# SqliteTaskRepository

SQLite-реализация `core::TaskRepository` по решениям 15, 23 и 40. Сохраняет
полные задачи, не меняя предметные правила TaskService.
Заголовок — `src/infra/include/msa/infra/SqliteTaskRepository.h`, реализация —
`src/infra/src/SqliteTaskRepository.cpp`.

## Схема и точки входа

Конструктор получает невладеющую ссылку на SqliteDatabase, открытую с полным
списком `sqliteMigrations()`. Владелец базы живёт дольше репозитория; все операции
выполняются в его потоке при живом QCoreApplication. Приложения пока не подключены.

Миграция 8 добавляет `tasks`: INTEGER PRIMARY KEY AUTOINCREMENT, полный заголовок,
необязательные год/месяц/день срока, приоритет 0/1/2, завершённость 0/1 и местные
секунды создания. CHECK запрещает частично заполненную дату. Отсутствие срока —
три NULL; прошлый срок допустим. Прежние таблицы миграция не меняет.

`add` принимает задачу с нулевым ID, сохраняет копию и назначает положительный ID.
`find` возвращает копию либо nullopt, `all` — независимые копии без гарантии порядка.
`update` заменяет все поля по ID, включая время и статус; сохранение этих полей
при предметном редактировании обеспечивает TaskService. Отсутствующая запись
даёт false, вставки вместо обновления нет. `remove` удаляет по ID, при отсутствии
возвращает false. ID удалённых зафиксированных записей не используются повторно.

Значения передаются параметрами подготовленных запросов. Пробелы, переносы,
Unicode, встроенный NUL и длинные заголовки сохраняются полностью. Репозиторий
не проверяет длину пользовательского названия и не обрезает его; это правило сервиса.
Неверная дата/приоритет и ненулевой ID новой записи — std::invalid_argument.
Ошибки SQL и некорректная дата/приоритет при чтении — std::runtime_error,
без маскировки отсутствующей задачей или пустым списком.

## Атомарность и ограничения

Каждая запись — один SQL-оператор и участвует во внешней транзакции SqliteDatabase.
Откат восстанавливает созданные, изменённые и удалённые задачи. Автоматической
очистки нет, импорт старой базы не выполняется. Сортировку делает TaskService.
Конкурентные изменения между find и update сервиса не согласуются. Все задачи
читаются целиком, постраничной загрузки нет. Часовые пояса не преобразуются.

## Тесты

`tests/infra/SqliteTaskRepositoryTest.cpp`: шесть файловых тестов. Проверяются
переход с версии 7 без потери дневника, повторное открытие и постоянные ID,
все поля и приоритеты, длинный текст с Unicode/NUL, копии, замена и снятие срока,
календарные границы, отсутствующие записи, удаление без повторного использования ID,
неверный ввод, ошибки SQL и откат всех видов записи. Связка с TaskService проверяет
сохранение времени создания и статуса при редактировании, завершение/возврат
задачи и предметную сортировку после открытия файла заново.
Команды — в [README](../../README.md).
