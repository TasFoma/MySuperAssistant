# Локальное хранилище спорта

`SqliteSportStore` в infra реализует порты SportWorkoutRepository,
SportProgramRepository и SportPreferencesRepository из core. Клиентская база
отдельна от серверной, использует Qt SQL/QSQLITE; серверные схемы/код не менялись.

## Идентичность и операции

application_id 0x4d535350, marker sport-client, версия схемы 3. Существующий файл
сначала открывается только для чтения. Чужая/более новая схема отклоняется.
Перед переходом версии создаётся согласованная копия VACUUM INTO, проверяются
quick_check, тип и версия; отказ резервирования останавливает миграцию.
Упражнения импортируются атомарно, существующая редакция неизменяема.

Checkpoint хранит типизированный draft, строки промежуточного ввода и номер.
Запись сравнивает ожидаемый номер; повтор идентичного запроса безопасен.
Завершение одной транзакцией пишет результат и снимает активную ссылку;
исправление сравнивает текущую редакцию и сохраняет старый снимок.
Неполный редакторский черновик собственной программы хранится отдельным
checkpoint, не становится готовой программой. История читает только текущие редакции. Предпочтения независимы от редакций текста.

## Кодек и ошибки

SportDocumentCodec использует версионированные JSON-документы агрегатов в SQLite.
Идентичности, номера и время не проходят через неточный JS double. Некорректные
поля/виды/версии, недопустимая нагрузка и неполный опубликованный контент
отклоняются. Ошибка не заменяет файл пустым состоянием. Соединение используется
только в потоке владельца; ошибки представлены исключением с общим русским текстом.

## Проверки и границы

SqliteSportStoreTest использует только QTemporaryDir. Проверяются интерфейсы
в памяти/на диске, восстановление, конфликт, импорт с откатом, резервирование,
чужая/новая схема, повреждение, отказ записи и программы-копии.
Синхронизации/очереди доставки нет. UI записи тренировок ещё не подключён;
серверные настройки не владеют этим хранилищем.

Windows проверяет исполнение QSQLITE на временных базах. Android Debug APK
содержит Qt6Sql и QSQLITE; драйвер также проверяется перед открытием при запуске.
Исполнение на Android требует проверки на подключённом устройстве.
