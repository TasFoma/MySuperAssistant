# MoodService

`msa::core::MoodService` записывает явно указанное настроение и читает дневник.
Заголовок — `src/core/include/msa/core/MoodService.h`, реализация —
`src/core/src/MoodService.cpp`. Зависимости Clock и MoodRepository передаются
невладеющими ссылками и должны жить дольше сервиса. API описан в Doxygen заголовков.
Правила согласованы решением 31.

## Данные и точки входа

- `MoodEntry` — ID, местное время записи с точностью до секунд, оценка MoodScore
  (Negative, Neutral, Positive) и полная заметка в UTF-8.
- `logMood` — проверяет оценку, получает время из Clock и добавляет запись.
  Пустая заметка разрешена, пробелы и переносы сохраняются. Обрезки до 120 символов
  нет. Повторный явный вызов создаёт отдельную запись.
- `moodHistory` — принимает положительное число календарных дней, по умолчанию 14.
  Включает сегодня и предыдущие дни с полуночи первого дня до текущего момента,
  включая обе границы. Сортирует по recordedAt, затем identifier, по возрастанию.
  Возвращает независимые копии; будущие записи исключаются.
- `MoodRepository` — добавление копии записи с нулевым ID и чтение копий всех
  записей без гарантии порядка. Деструктор — `src/core/src/MoodRepository.cpp`.
  Интерфейс не содержит очистки по возрасту; положительный ID назначает хранилище.

Неверная оценка или неположительный период дают MoodRejection с причиной до
обращения к репозиторию. Технические ошибки хранилища пробрасываются исключениями.

## Сохранность и ограничения

Период просмотра не ограничивает срок хранения. История за 14 дней не удаляет
старые записи; больший период позволяет снова их получить. Дневник не переносит
данные в профиль и не удаляет их после чтения.

Запись выполняется только по явному вызову. Сервис не анализирует текст и не решает,
является ли сообщение ответом на опрос или просьбой записать настроение. Это будет
обязанностью обработки чата; словарный анализ не переносится. Анализ через LLM,
автоматическое выделение биографических фактов и поддерживающие подсказки пока отсутствуют.

Приложения пока не создают сервис. Реализация InMemoryMoodRepository существует
только в тестах; данные не сохраняются между запусками процесса. SQLite появится
на этапе 3. История читает весь репозиторий и фильтрует копии в памяти; индексация
и запросы по диапазону пока не реализованы. Время — местная шкала сервера без
преобразования часовых поясов. Предполагаются последовательные вызовы.

## Тесты

`tests/core/MoodServiceTest.cpp`: все три оценки, полная длинная заметка с русским
текстом и переносом строки, пустые и повторные записи, время из FakeClock, точные
границы периода, исключение будущих записей, смена дня через год и февраль,
сортировка и независимость копий, восстановление старой записи расширением периода,
проверки ввода до обращения к хранилищу, ошибки чтения и сохранения.
Контракт InMemoryMoodRepository проверяется в том же файле через MoodRepository.
Команды сборки и тестов — в [README](../../README.md).
