# UserProfileService

Добавление фактов памяти пользователя без Qt, файлов и сети. Единственная
зависимость — `UserProfileRepository`, переданный через конструктор.

## Точки входа

- `rememberFact` — обрезает пробельные символы Unicode по краям, отклоняет пустой
  результат либо добавляет факт в конец загруженного профиля и сохраняет профиль целиком.
- `profile` — возвращает независимую копию всех фактов в порядке добавления.

## Правила

Сохраняются все факты, включая повторы. Внутренние пробелы и переносы строк
не меняются; многострочный текст занимает один элемент списка. Маркеры оформления
не добавляются. Ограничение последних 30 фактов отменено решением 27.
Функция обрезки находится во внутреннем `Utf8Text`, ожидающем текст UTF-8.

Неверный ввод возвращает `UserProfileRejection` с причиной без обращения к
репозиторию. Успех — `std::monostate`. Технические исключения пробрасываются.

## Ограничения и тесты

Сервис пока не связан с парсером и приложениями. Нет SQLite, тегов, поиска,
отбора памяти для LLM или ограничения контекста: это отдельные шаги плана.
Весь профиль загружается и сохраняется целиком; нет защиты от потерянных
обновлений при конкурентных операциях. Уже сохранённые факты не нормализуются.

`tests/core/UserProfileServiceTest.cpp` проверяет сохранение более 30 фактов без
потерь и в исходном порядке, чтение через другой экземпляр сервиса, независимость
копий, повторы, односимвольный и многострочный текст, пробельные символы Unicode,
отказ без доступа к хранилищу и проброс ошибок чтения/сохранения.
