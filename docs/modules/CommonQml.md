# Общие QML-компоненты

Модуль `Msa.Ui.Common 1.0` в `src/ui/common/qml/` содержит общую визуальную
основу desktop/mobile. Qt Quick Controls Basic обеспечивают стандартную обработку
клавиатуры, фокуса и ввода и допускают общую отрисовку на разных платформах.
Сторонних библиотек и внешних шрифтов нет.

## Точки входа

- `Theme.qml` — единственный источник цветов, системного шрифта, размеров,
  отступов, радиусов и длительности короткого перехода цвета кнопки.
- `AppButton`, `AppTextField`, `AppTextArea` — кнопка с тремя тонами и поля ввода.
- `SurfaceCard`, `SectionHeader` — контейнер и заголовок раздела.
- `TaskRow` — задача и сигнал `doneRequested(identifier, done)`.
- `MessageBubble` — автор, выбираемый обычный текст, время, входящее/исходящее сообщение.
- `HabitProgress` — прогресс и готовая строка количества из C++.
- `ConnectionBanner` — статус, признак последних данных и `reconnectRequested()`.
- `ErrorBanner` — ошибка и необязательное явно разрешённое `actionRequested()`.
- `EmptyState` — заголовок и пояснение пустого списка.

## Данные и действия

Компоненты принимают свойства, не знают о сети и не выбирают правила предметной
области. Экран связывает их с ClientModels/ролями списка. Строки сроков,
приоритетов, количества и статуса готовит C++; значения ID остаются строками.
`TaskRow.actionsEnabled` задаётся доступностью серверного действия. Клик только
испускает запрос; чекбокс ждёт нового значения `done` после подтверждения.
Последние данные можно показывать с `stale`; сообщения остаются выбираемыми.
HTML в сообщениях не исполняется: используется PlainText.

Кнопка ConnectionBanner доступна по `ClientModels.reconnectAvailable` после
остановки попыток (Disconnected/Exhausted); действие вызывает `ClientModels.reconnect()`.
Компонент не содержит таймеров и не повторяет запись. ErrorBanner по умолчанию
не показывает действие: неизвестный исход записи сам по себе не разрешает retry.
Шкалу прогресса ограничивает стандартный ProgressBar, исходные числа не меняются.

## Сборка и ограничения

`qt_add_qml_module(msa_ui_common URI Msa.Ui.Common)` помещает QML в ресурсы;
`msa_ui_commonplugin` линкуется с desktop/mobile и импортируется через
`Q_IMPORT_QML_PLUGIN(MsaUiCommonPlugin)`. Тема — QML singleton с readonly-токенами,
без состояния приложения. Основные приложения пока не создают QML-окно.
Навигация, экраны, постоянные настройки и оставшиеся формы действий впереди.
Android пока не проверен.

## Проверки

`tests/infra/CommonComponentsTest.cpp` и `qml/CommonComponentsGallery.qml`
проверяют импорт модуля, отсутствие QML-предупреждений, активацию клавиатурой,
Unicode-ввод, подтверждение задачи, текст/прогресс, отключённые действия,
переподключение и ширину 360 px. Отдельный `msa_ui_tests` использует
QGuiApplication, offscreen и программный рендеринг; существующие infra-тесты
сохраняют QCoreApplication. Видимое окно и настоящий сервер не запускаются.
На Windows тесты читают системные шрифты из WINDIR/Fonts и выбирают Segoe UI,
если он установлен: offscreen не получает обычный шрифт от оконного плагина.
Галерея — тестовый стенд, не макет согласованного экрана. Рендер сохраняется
в `out/build/windows-debug-local/common-components-preview.png`.
Команды сборки и CTest — в [README](../../README.md).
