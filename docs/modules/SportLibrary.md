# Офлайн-библиотека спорта

## Точки входа и данные

`SportLibraryModel` в ui/common/Model принимает каталог и подтверждённые
предпочтения типами core. `SportController` в apps/common читает встроенный
пакет через infra/SportCatalog, импортирует редакции в SqliteSportStore,
применяет результат к UI. TCP-сессия не участвует. Смена её настроек не очищает
и не открывает спортивную базу повторно.

`SportLibraryPanel.qml` и SportFilterBox используют общую Theme/Controls.
WorkoutsScreen и MobileSportScreen связывают одну модель своего клиента с панелью.
На широкой области список и карточка рядом, на узкой — последовательный просмотр.
Фильтры сворачиваются, при IME освобождается место. MobileState обрабатывает
Назад после общей формы: карточка → список → обзор спорта → Сегодня.

## Состав и редакционные ограничения

Пакет `src/infra/resources/SportExercises.json` содержит 22 устойчивые идентичности.
Полностью заполнены и опубликованы 6 карточек: 03, 05, 06, 07, 11, 12.
Это приседание без веса, фронтальное приседание с гантелями, мост, тяга с гантелями,
отжимания с колен и обычные. Краткая/полная техника, мышцы, оборудование, ошибки,
условия, правила учёта и источники сверены с первичными ACE/NASM 2026-11-24.
Каждый текст — краткий оригинальный русский конспект; изображения не загружались.
Где отдельная схема дыхания первоисточником не задана, это явно написано.

16 остальных карточек остаются неопубликованными метаданными; в рабочем списке
они не выдаются за готовые. У альтернатив виден статус подготовки.
P1/P3 выбраны, но готовые программы/подходы/повторения ещё не опубликованы.
Ни P1, ни альтернативы не назначаются автоматически по боли/самочувствию.
Следующее заполнение карточки получает новую редакцию: уже импортированное
содержимое прежней редакции неизменяемо, пользовательские отметки привязаны к ID.

## Поиск, фильтры и отметки

Поиск локальный, по всем словам названия/синонимов/мышц; регистр и е/ё не различаются.
Инвентарь проверяется по доступному набору, мышцы/избранное/предпочтение прогресса
сочетаются через И; отдельно доступны условия без выхода на пол и без опоры на кисти.
Ни один фильтр не означает медицинский допуск.

Избранное и «Хочу прогрессировать» независимы. Модель испускает запрос, apps пишет
в SQLite и лишь после успеха подтверждает отметку. Ошибка не переключает её;
ошибка чтения сохраняет последние отметки в памяти, но отключает новую запись.
Карточки продолжают читаться из встроенного ресурса при недоступной базе.

Путь основных EXE — AppLocalDataLocation/sport/sport-local.sqlite.
CLI `--sport-data <path>` задаёт отдельный путь для изолированной проверки.
Runtime без явно переданного пути читает каталог без записи; точки входа EXE
задают обычный путь, тесты — только QTemporaryDir.

## Проверки и оставшаяся работа

SportLibraryTest проверяет полноту опубликованного поднабора, поиск/фильтры,
сохранность независимых отметок, ошибку записи/восстановления и настоящие QML
оболочки на Desktop и мобильных размерах. Свежие снимки с Overlay сохраняются
в out/build/windows-debug-local/sport-*.png.

Экран записи тренировки, управление таймером с UI, редактор собственных программ,
просмотр/исправление истории и визуализация динамики ещё не подключены.
Core и локальное хранение для этих операций есть; сеть/Лама не используются.
