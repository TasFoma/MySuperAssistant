# Журнал уроков

Грабли, на которые уже наступали: что случилось и как этого избегать.
Это не история работы и не архитектурные решения (они в `docs/decisions.md`).

Формат записи:

```
## <Короткая тема>
- **Дата:** ГГГГ-ММ-ДД
- **Что случилось:** одно-два предложения.
- **Правило:** что делать, чтобы не повторилось.
```

Когда урок становится правилом в `AGENTS.md`, запись отсюда удаляется.

## Минимальная высота чата в Qt Quick Layouts
- **Дата:** 2026-11-09
- **Что случилось:** в окне 1000×720 кнопки помещались, но фиксированная
  implicitHeight редактора сжимала ListView до обрезанного заголовка сообщения.
- **Правило:** задать минимум прокручиваемой области, а редактору разрешить
  уменьшение через fillHeight и minimumHeight/maximumHeight. Проверять в минимальном
  окне не только границы кнопок, но и доступную высоту содержимого; смотреть рендер.

## Qt Speech: документация и бинарный модуль
- **Дата:** 2026-11-09
- **Что случилось:** после выбора Speech для Qt 6.10.3 установились docs/examples,
  но не было MSVC-кита и Qt6TextToSpeechConfig.cmake; текущая сборка использовала 6.10.2.
- **Правило:** проверять Core и TextToSpeech в одном установленном ките, а не только
  галочку модуля или наличие документации. В Maintenance Tool нужен MSVC 2022
  64-bit и бинарный Speech этой же версии; компоненты разных Qt не смешивать.

## Невидимые символы в именах файлов
- **Дата:** 2026-11-09
- **Что случилось:** чтение docs/old-project-overview.md по видимому имени
  не находило существующий файл: после расширения в имени стоит U+200E.
- **Правило:** если файл виден в поиске, но не открывается по набранному пути,
  получить его точный путь через rg --files с узкой маской и передать в
  Get-Content -LiteralPath; не переименовывать файл без согласования пользователя.

## Отложенный отказ при уничтожении транспорта
- **Дата:** 2026-11-09
- **Что случилось:** disconnectFromServer ставит requestFailed в очередь событий;
  немедленное удаление TcpClient при смене endpoint отменяет эти сигналы, и UI
  может не узнать о неизвестном исходе ожидавшей записи.
- **Правило:** перед уничтожением связки явно завершать её ожидавшие записи как
  unknown и блокировать повтор; не рассчитывать на доставку queued-сигнала
  удаляемого QObject. Проверять смену сервера с уже отправленной записью без ack.

## Регистрация типов сигналов в Qt 6
- **Дата:** 2026-11-09
- **Что случилось:** Q_DECLARE_METATYPE для MusicTracks во втором заголовке
  конфликтовал с уже созданным метатипом первого класса в общей moc-компиляции.
- **Правило:** для полных типов в типизированных сигналах Qt 6 не добавлять позднюю
  специализацию Q_DECLARE_METATYPE; имя для queued-соединения регистрировать
  через qRegisterMetaType до соединения. Проверять передачу настоящим потоком.

## Имена id и свойства Qt Controls
- **Дата:** 2026-11-09
- **Что случилось:** id внешней формы popup перекрылся свойством ComboBox.popup;
  popup.editor внутри списка обращался к другому объекту и выдавал TypeError.
- **Правило:** давать внешним QML-объектам конкретные id (например plannerPopup),
  проверять привязки и события вложенных Controls настоящим вводом в GUI-тесте.

## Поиск QML-делегатов в GUI-тестах
- **Дата:** 2026-11-09
- **Что случилось:** QObject::findChild не находил кнопки Repeater и строки задач,
  хотя они отображались: владение QObject и визуальное родительство QQuickItem различаются.
- **Правило:** искать элементы интерфейса по childItems визуального дерева;
  перед снимком дать завершиться layout и коротким переходам цвета.

## Шрифты в offscreen-тестах Windows
- **Дата:** 2026-11-09
- **Что случилось:** offscreen-плагин Qt не нашёл системные шрифты, и рендер
  показал квадраты вместо букв при успешной загрузке QML.
- **Правило:** для offscreen-тестов Windows задавать QT_QPA_FONTDIR из WINDIR/Fonts
  и просматривать сохранённый рендер: непустой PNG ещё не проверяет читаемость.

## Имена свойств темы QML
- **Дата:** 2026-11-09
- **Что случилось:** имя цвета onAccent было воспринято QML как обработчик
  сигнала, и тема не загружалась, хотя компиляция QML-кэша прошла.
- **Правило:** не начинать имена токенов с on и заглавной буквы; проверять
  загрузку модуля через QQmlEngine, а не только сборку кэша.

## Статический QML-плагин и C++ API
- **Дата:** 2026-11-09
- **Что случилось:** тест, связанный только с msa_ui_commonplugin, не видел
  заголовки ClientModels и Qt Quick: плагин не экспортирует C++ API своей библиотеки.
- **Правило:** потребитель C++ API линкует сам msa_ui_common; для импорта QML
  дополнительно линкует msa_ui_commonplugin и импортирует его в точке входа.

## Отказ чтения не должен запускать тот же refresh
- **Дата:** 2026-11-09
- **Что случилось:** при проверке клиентской связки найден безусловный refresh
  в обработчике отказа; ошибка profile.get могла повторять сама себя без остановки.
- **Правило:** обновлять данные после предметного действия/события, но не повторять
  отказавшее чтение без отдельного основания.

## Qt-журнал дочернего процесса
- **Дата:** 2026-11-09
- **Что случилось:** запущенный через QProcess сервер не отдавал сообщение
  о порте в перенаправленные каналы; тесты ошибочно считали запуск неуспешным.
- **Правило:** если тест читает готовность из Qt-журнала дочернего процесса,
  задать ему QT_FORCE_STDERR_LOGGING=1 и при отказе показывать состояние/ошибку процесса.

## Повторная проверка ожидания не должна читать сокет
- **Дата:** 2026-11-09
- **Что случилось:** помощник ожидания вызывал предикат ещё раз после успеха.
  Предикат чтения уже забрал ответ и при повторном вызове сообщал ложный тайм-аут
  или поглощал следующий ответ.
- **Правило:** предикат с чтением буфера после найденного результата должен
  возвращать сохранённый успех без нового чтения; проверять ответы по request_id.

## Цели Qt видны только там, где их нашли
- **Дата:** 2026-11-04
- **Что случилось:** `find_package(Qt6 ... Quick)` внутри `src/ui/...` — приложение в `src/apps/desktop`
  не видело `Qt6::Quick`, Qt выдавал предупреждение при финализации.
- **Правило:** Qt ищется один раз в корневом `CMakeLists.txt`, в подпапках `find_package(Qt6)` не вызывать.

## Генератор Visual Studio многоконфигурационный
- **Дата:** 2026-10-27
- **Что случилось:** `CMAKE_BUILD_TYPE` в пресете ни на что не влиял, release-пресет собирал Debug.
- **Правило:** конфигурацию задаёт build preset (`"configuration"`), у `ctest` — флаг `-C Debug`.

## Тесты из старой сборки
- **Дата:** 2026-11-04
- **Что случилось:** после правки CMake запустили `ctest` без пересборки — прошёл старый smoke-тест,
  новый код не собирался вовсе.
- **Правило:** после изменений сначала конфигурация и сборка, потом `ctest`; сверить имена тестов в выводе.

## Конфигурация может обновлять уже скачанные зависимости
- **Дата:** 2026-11-06
- **Что случилось:** `FetchContent` остановил конфигурацию без доступа к GitHub:
  шаг обновления PCRE2 выполнялся, хотя исходники уже были скачаны.
- **Правило:** сеть может понадобиться и при повторной конфигурации. При сетевой
  ошибке агент повторяет разрешённую команду с запросом сетевого доступа.
  После правки теста, зарегистрированного через gtest_add_tests, сборка может
  автоматически повторить конфигурацию и снова потребовать сеть; сначала повторить
  разрешённую команду конфигурации с доступом к сети, затем сборку.

## Русский текст в исходниках MSVC
- **Дата:** 2026-10-27
- **Что случилось:** без флага `/utf-8` MSVC выдаёт C4819 на русские комментарии и неверно читает
  русские строковые литералы.
- **Правило:** `/utf-8` задан в `cmake/Warnings.cmake`; не убирать.
  Строки UTF-8 преобразовывать через QString::fromUtf8; QLatin1String годится
  только для Latin-1, русские подписи через него искажаются даже с /utf-8.

## Длина строки в символах, а не байтах
- **Дата:** 2026-10-27
- **Что случилось:** пороги вида «заголовок не короче 3 символов» считались через `size()` — для русского
  текста в UTF-8 это байты, одно слово из 3 букв давало 6.
- **Правило:** длину текста для пользователя считать в символах (`charCount` из `Utf8Text`).

## Личные пресеты не видны агенту
- **Дата:** 2026-10-27
- **Что случилось:** агент предлагал пресет `windows-debug`, потому что `CMakeUserPresets.json`
  в `.gitignore` и он его не видел.
- **Правило:** работать с пресетами `windows-debug-local` / `windows-release-local`
  (шаблон — `CMakeUserPresets.json.example`).

## Смена даты во время запроса к модели
- **Дата:** 2026-11-06
- **Что случилось:** проверка срока ожидания до вызова LLM не учитывала, что ответ
  может прийти после полуночи. Это позволяло записать ответ на уже истёкший опрос.
- **Правило:** перед выполнением действия после долгого внешнего вызова повторно
  проверять временное состояние; переход даты проверять с управляемыми часами.

## [[nodiscard]] внутри EXPECT_THROW на MSVC
- **Дата:** 2026-11-07
- **Что случилось:** GoogleTest не подавляет C4834 для вызова [[nodiscard]] внутри
  EXPECT_THROW, хотя результат намеренно не нужен при проверке исключения.
- **Правило:** писать `EXPECT_THROW(static_cast<void>(service.method()), ExceptionType)`;
  предупреждения проекта не отключать.

## Знаки плюс и проценты в QUrlQuery
- **Дата:** 2026-11-07
- **Что случилось:** QUrlQuery сохраняет буквальный `+`, который сервер HTML-форм
  может прочитать как пробел; необработанная последовательность `%2B` тоже меняет смысл.
- **Правило:** перед addQueryItem кодировать пользовательский ввод через
  QUrl::toPercentEncoding. Проверять отправленный URL и однократное декодирование
  формы на запросах с `C++`, `%2B` и `&`, а не только обратное чтение через QUrlQuery.
