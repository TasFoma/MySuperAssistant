# Журнал уроков

Грабли, на которые уже наступали: что случилось и как этого избегать.
Это не история работы и не архитектурные решения (они в `docs/decisions.md`).

Формат записи:

```
## <Короткая тема>
- **Дата:** ГГГГ-ММ-ДД
- **Что случилось:** одно-два предложения.
- **Правило:** что делать, чтобы не повторилось.
```

Когда урок становится правилом в `AGENTS.md`, запись отсюда удаляется.

## Android IME: offscreen-размер не проверяет режим окна
- **Дата:** 2026-11-22
- **Что случилось:** на A55 Android 16 окно Qt по умолчанию сдвигалось при
  клавиатуре; часть поля и кнопка отправки оставались под IME. Offscreen-тесты
  с уменьшенной высотой проходили, потому что само окно в них уже было уменьшено.
- **Правило:** AndroidManifest задаёт windowSoftInputMode="adjustResize";
  после упаковки проверять атрибут в APK и реальную клавиатуру на устройстве.
  Общую вёрстку и режим Android-окна проверять отдельно. Штатная упаковка шаблона:
  [QT_ANDROID_PACKAGE_SOURCE_DIR](https://doc.qt.io/qt-6.10/cmake-target-property-qt-android-package-source-dir.html).

## Якоря Popup отличаются от якорей Item
- **Дата:** 2026-11-22
- **Что случилось:** QML компилировался, но общий диалог не загружался:
  Popup.anchors не поддерживает horizontalCenterOffset/verticalCenterOffset.
- **Правило:** Popup со смещением для SafeArea размещать через x/y относительно
  Overlay и ограничивать ширину/высоту доступной областью. Проверять загрузку
  настоящего компонента offscreen, одной компиляции QML недостаточно.

## Свежий кадр offscreen после смены раздела
- **Дата:** 2026-11-22
- **Что случилось:** grabWindow после нескольких переходов сохранял снимок
  без нижней панели, хотя геометрия и isVisible панели оставались корректными.
- **Правило:** в размерных мобильных тестах вызывать grabToImage и ждать ready;
  захватывать contentItem окна, чтобы в снимок попали также диалоги Overlay.

## Успешная сборка не размещает DLL Qt рядом с EXE
- **Дата:** 2026-11-21
- **Что случилось:** запуск desktop из Проводника завершался отсутствием
  Qt6Guid.dll. CTest добавлял Qt в PATH, поэтому тест запуска не замечал проблему.
- **Правило:** Windows-сборка desktop выполняет windeployqt с QML-сканированием
  и зависимостями голосового worker. Тест запуска очищает PATH от Qt и переменные
  путей плагинов/QML. Отдельный EXE нельзя переносить без соседних зависимостей.
  При общем выходном каталоге учитывать другие приложения: локальный Qt Core
  меняет поиск плагинов, поэтому драйвер SQLite и offscreen-плагин тестов включены явно.

## TCP-слушатель требует адрес, назначенный целевому ноутбуку
- **Дата:** 2026-11-15
- **Что случилось:** после переноса сервер завершился с отказом открытия TCP-порта.
  На рабочем ноутбуке порт был свободен, но адаптер Tailscale имел только link-local
  адрес, а адрес из listen_address не был назначен интерфейсу.
- **Правило:** при таком отказе проверить адрес адаптера и занятость порта на
  целевой машине. Сначала подключить Tailscale и сверить его текущий IP с JSON;
  не подменять адрес на 0.0.0.0 и не пересобирать приложение ради ошибки привязки.

## Запуск NDK из песочницы агента
- **Дата:** 2026-11-15
- **Что случилось:** Android-конфигурация прошла, но AUTOMOC не смог запустить
  установленный NDK clang++: Permission denied. Та же сборка с расширенным
  доступом успешно создала APK без изменения кода и настройки инструментов.
- **Правило:** при отказе запуска NDK из песочницы повторить разрешённую команду
  сборки с запросом доступа; не переустанавливать NDK и не менять права файлов.

## Собственные QML-модули при упаковке Android
- **Дата:** 2026-11-10
- **Что случилось:** статические плагины линковались, но androiddeployqt
  не находил Msa.Ui.Common при сканировании импортов нового мобильного модуля.
- **Правило:** задавать QT_QML_IMPORT_PATH цели приложения с корнями build-каталогов
  собственных модулей; линковка плагина не заменяет пути сканера. Для путей
  в формате CMake явно включать политику Qt QTP0002 NEW.

## Повторный C1033 на сгенерированной PDB
- **Дата:** 2026-11-10
- **Что случилось:** после прерывания сборки MSVC повторно не открывал
  msa_ui_common.pdb, хотя файл не был заблокирован и запуск вне песочницы не помог.
  После согласованного переименования в .pdb.backup компиляция продолжилась.
- **Правило:** при C1033 проверить доступ и оставшиеся процессы; не запускать
  вторую сборку в том же каталоге до завершения первой. Если отказ остаётся,
  согласовать резервное переименование конкретной PDB, не чистить всё дерево.

## GUI-тесты и первая Android-сборка
- **Дата:** 2026-11-10
- **Что случилось:** при одновременной первой Android-компиляции тест запуска
  desktop не дождался двух запросов за пять секунд. После завершения C++-компиляции
  повторный полный прогон прошёл: 516 из 516; точная причина задержки не установлена.
- **Правило:** не совмещать первую тяжёлую сборку с GUI-тестами, ограниченными
  коротким сроком. При единичном тайм-ауте сначала проверить без нагрузки,
  не увеличивать сроки и не менять поведение приложения без воспроизведения.

## ADB и пользовательский профиль в песочнице агента
- **Дата:** 2026-11-10
- **Что случилось:** обычный запуск adb завершился `Cannot mkdir '\.android': Permission denied`,
  хотя проверка с доступом к настоящему профилю уже видела телефон как unauthorized.
- **Правило:** для проверки USB-устройства из окружения агента запрашивать доступ
  к пользовательскому профилю ADB; не создавать новые ключи и не менять HOME ради обхода.

## Регистрозависимые шаблоны в PowerShell
- **Дата:** 2026-11-09
- **Что случилось:** шаблон `[a-z]` в `-replace` совпадал и с Qt-заголовками,
  потому что оператор по умолчанию не учитывает регистр; группы include разбились неверно.
- **Правило:** для преобразований с различием `[A-Z]`/`[a-z]` применять `-creplace`
  и проверять результат на одном файле до пакетной правки.

## Минимальная высота чата в Qt Quick Layouts
- **Дата:** 2026-11-09
- **Что случилось:** в окне 1000×720 кнопки помещались, но фиксированная
  implicitHeight редактора сжимала ListView до обрезанного заголовка сообщения.
- **Правило:** задать минимум прокручиваемой области, а редактору разрешить
  уменьшение через fillHeight и minimumHeight/maximumHeight. Проверять в минимальном
  окне не только границы кнопок, но и доступную высоту содержимого; смотреть рендер.
  Для Controls.TextArea измерять layout-прямоугольник по width/height:
  boundingRect может описывать отрисованный текст, а не всё поле ввода.
  Панели статуса с неизменной высотой задавать минимум implicitHeight, чтобы
  длинное прокручиваемое содержимое не сжимало их.
  Для дополнительной прокрутки всего чата не связывать высоту дочернего layout
  с availableHeight ScrollView и обратно с contentHeight: это вызвало binding loop.
  Использовать Flickable с независимым размером области, явным contentHeight
  и минимальной высотой содержимого; проверять состояние с высокой панелью ошибки.

## Qt Speech: документация и бинарный модуль
- **Дата:** 2026-11-09
- **Что случилось:** после выбора Speech для Qt 6.10.3 установились docs/examples,
  но не было MSVC-кита и Qt6TextToSpeechConfig.cmake; текущая сборка использовала 6.10.2.

  64-bit и бинарный Speech этой же версии; компоненты разных Qt не смешивать.

## Невидимые символы в именах файлов
- **Дата:** 2026-11-09
- **Что случилось:** чтение docs/old-project-overview.md по видимому имени
  не находило существующий файл: после расширения в имени стоит U+200E.
- **Правило:** если файл виден в поиске, но не открывается по набранному пути,
  получить его точный путь через rg --files с узкой маской и передать в
  Get-Content -LiteralPath; не переименовывать файл без согласования пользователя.

## Отложенный отказ при уничтожении транспорта
- **Дата:** 2026-11-09
- **Что случилось:** disconnectFromServer ставит requestFailed в очередь событий;
  немедленное удаление TcpClient при смене endpoint отменяет эти сигналы, и UI
  может не узнать о неизвестном исходе ожидавшей записи.
- **Правило:** перед уничтожением связки явно завершать её ожидавшие записи как
  unknown и блокировать повтор; не рассчитывать на доставку queued-сигнала
  удаляемого QObject. Проверять смену сервера с уже отправленной записью без ack.

## Регистрация типов сигналов в Qt 6
- **Дата:** 2026-11-09
- **Что случилось:** Q_DECLARE_METATYPE для MusicTracks во втором заголовке
  конфликтовал с уже созданным метатипом первого класса в общей moc-компиляции.
- **Правило:** для полных типов в типизированных сигналах Qt 6 не добавлять позднюю
  специализацию Q_DECLARE_METATYPE; имя для queued-соединения регистрировать
  через qRegisterMetaType до соединения. Проверять передачу настоящим потоком.

## Имена id и свойства Qt Controls
- **Дата:** 2026-11-09
- **Что случилось:** id внешней формы popup перекрылся свойством ComboBox.popup;
  popup.editor внутри списка обращался к другому объекту и выдавал TypeError.
- **Правило:** давать внешним QML-объектам конкретные id (например plannerPopup),
  проверять привязки и события вложенных Controls настоящим вводом в GUI-тесте.

## Поиск QML-делегатов в GUI-тестах
- **Дата:** 2026-11-09
- **Что случилось:** QObject::findChild не находил кнопки Repeater и строки задач,
  хотя они отображались: владение QObject и визуальное родительство QQuickItem различаются.
- **Правило:** искать элементы интерфейса по childItems визуального дерева;
  перед снимком дать завершиться layout и коротким переходам цвета.
  После увеличения длительности перехода перепроверять паузу в тестах:
  120–150 мс недостаточно для перехода 140 мс и следующего offscreen-кадра.
  При нескольких экземплярах общего компонента искать действие внутри нужного
  контейнера: одинаковый objectName внутренней кнопки может принадлежать скрытому
  образцу галереи. Порядок создания объектов не определяет нужное действие.

## Шрифты в offscreen-тестах Windows
- **Дата:** 2026-11-09
- **Что случилось:** offscreen-плагин Qt не нашёл системные шрифты, и рендер
  показал квадраты вместо букв при успешной загрузке QML.
- **Правило:** для offscreen-тестов Windows задавать QT_QPA_FONTDIR из WINDIR/Fonts
  и просматривать сохранённый рендер: непустой PNG ещё не проверяет читаемость.

## Имена свойств темы QML
- **Дата:** 2026-11-09
- **Что случилось:** имя цвета onAccent было воспринято QML как обработчик
  сигнала, и тема не загружалась, хотя компиляция QML-кэша прошла.
- **Правило:** не начинать имена токенов с on и заглавной буквы; проверять
  загрузку модуля через QQmlEngine, а не только сборку кэша.

## UTF-8 в служебной строке QML_UNCREATABLE
- **Дата:** 2026-11-22
- **Что случилось:** moc Qt 6.10.3 разделил длинную русскую строку причины
  QML_UNCREATABLE посреди UTF-8-символа; MSVC получил C4828/C2001 в generated-файле.
- **Правило:** для этой служебной причины использовать короткую ASCII-строку;
  пользовательские подписи и комментарии оставлять русскими. Проверять исходный
  заголовок и результат moc, не исправлять generated-файл и не отключать /utf-8.

## Регистратор QML включает заголовок по короткому имени
- **Дата:** 2026-11-22
- **Что случилось:** после QML_ELEMENT generated-регистратор включал
  DesktopState.h без msa/ui; __has_include пропускал заголовок и тип не находился.
- **Правило:** целевой библиотеке дать PRIVATE-путь к конкретной папке заголовка
  внутри include. Публичным оставить Model/include; не экспортировать src и
  не править generated-файл.

## Отключение кнопки во время перехода цвета
- **Дата:** 2026-11-21
- **Что случилось:** на рендере формы отключённая кнопка ещё имела акцентный фон
  незавершённого ColorAnimation; отключение Behavior не устранило промежуточный кадр.
- **Правило:** анимировать обычный/hover-цвет отдельно; фон disabled и pressed
  выбирать напрямую, независимо от анимируемого значения. Проверять отключение
  во время перехода, а не только кнопку, созданную сразу недоступной.

## Статический QML-плагин и C++ API
- **Дата:** 2026-11-09
- **Что случилось:** тест, связанный только с msa_ui_commonplugin, не видел
  заголовки ClientModels и Qt Quick: плагин не экспортирует C++ API своей библиотеки.
- **Правило:** потребитель C++ API линкует сам msa_ui_common; для импорта QML
  дополнительно линкует msa_ui_commonplugin и импортирует его в точке входа.

## Отказ чтения не должен запускать тот же refresh
- **Дата:** 2026-11-09
- **Что случилось:** при проверке клиентской связки найден безусловный refresh
  в обработчике отказа; ошибка profile.get могла повторять сама себя без остановки.
- **Правило:** обновлять данные после предметного действия/события, но не повторять
  отказавшее чтение без отдельного основания.

## Qt-журнал дочернего процесса
- **Дата:** 2026-11-09
- **Что случилось:** запущенный через QProcess сервер не отдавал сообщение
  о порте в перенаправленные каналы; тесты ошибочно считали запуск неуспешным.
- **Правило:** если тест читает готовность из Qt-журнала дочернего процесса,
  задать ему QT_FORCE_STDERR_LOGGING=1 и при отказе показывать состояние/ошибку процесса.

## Повторная проверка ожидания не должна читать сокет
- **Дата:** 2026-11-09
- **Что случилось:** помощник ожидания вызывал предикат ещё раз после успеха.
  Предикат чтения уже забрал ответ и при повторном вызове сообщал ложный тайм-аут
  или поглощал следующий ответ.
- **Правило:** предикат с чтением буфера после найденного результата должен
  возвращать сохранённый успех без нового чтения; проверять ответы по request_id.

## Цели Qt видны только там, где их нашли
- **Дата:** 2026-11-04
- **Что случилось:** `find_package(Qt6 ... Quick)` внутри `src/ui/...` — приложение в `src/apps/desktop`
  не видело `Qt6::Quick`, Qt выдавал предупреждение при финализации.
- **Правило:** Qt ищется один раз в корневом `CMakeLists.txt`, в подпапках `find_package(Qt6)` не вызывать.

## Генератор Visual Studio многоконфигурационный
- **Дата:** 2026-10-27
- **Что случилось:** `CMAKE_BUILD_TYPE` в пресете ни на что не влиял, release-пресет собирал Debug.
- **Правило:** конфигурацию задаёт build preset (`"configuration"`), у `ctest` — флаг `-C Debug`.

## Тесты из старой сборки
- **Дата:** 2026-11-04
- **Что случилось:** после правки CMake запустили `ctest` без пересборки — прошёл старый smoke-тест,
  новый код не собирался вовсе.
- **Правило:** после изменений сначала конфигурация и сборка, потом `ctest`; сверить имена тестов в выводе.

## Конфигурация может обновлять уже скачанные зависимости
- **Дата:** 2026-11-06
- **Что случилось:** `FetchContent` остановил конфигурацию без доступа к GitHub:
  шаг обновления PCRE2 выполнялся, хотя исходники уже были скачаны.
- **Правило:** сеть может понадобиться и при повторной конфигурации. При сетевой
  ошибке агент повторяет разрешённую команду с запросом сетевого доступа.
  После правки теста, зарегистрированного через gtest_add_tests, сборка может
  автоматически повторить конфигурацию и снова потребовать сеть; сначала повторить
  разрешённую команду конфигурации с доступом к сети, затем сборку.

## Русский текст в исходниках MSVC
- **Дата:** 2026-10-27
- **Что случилось:** без флага `/utf-8` MSVC выдаёт C4819 на русские комментарии и неверно читает
  русские строковые литералы.
- **Правило:** `/utf-8` задан в `cmake/Warnings.cmake`; не убирать.
  Строки UTF-8 преобразовывать через QString::fromUtf8; QLatin1String годится
  только для Latin-1, русские подписи через него искажаются даже с /utf-8.

## Длина строки в символах, а не байтах
- **Дата:** 2026-10-27
- **Что случилось:** пороги вида «заголовок не короче 3 символов» считались через `size()` — для русского
  текста в UTF-8 это байты, одно слово из 3 букв давало 6.
- **Правило:** длину текста для пользователя считать в символах (`charCount` из `Utf8Text`).

## CMake Tools показывает не тот каталог, который собирает
- **Дата:** 2026-11-15
- **Что случилось:** VS Code показывал Building folder windows-debug-local,
  но запускал windows-debug при правильно выбранных local-пресетах. Повторный
  выбор не помог: причина — наследование binaryDir с ${presetName}, ошибка
  [#5124](https://github.com/microsoft/vscode-cmake-tools/issues/5124). Парсер
  установленной версии 1.25.10 воспроизвёл подстановку имени родителя.
- **Правило:** явно задавать binaryDir в каждом личном configure preset, как
  в обновлённом шаблоне. Проверять исполняемую команду и подстановку расширения;
  успешная CLI-сборка не доказывает исправление CMake Tools. Не сводить причину
  к выбору пользователя и не удалять сборки без проверки. После правки дождаться
  перечитывания файла, при оставшемся старом состоянии перезагрузить окно VS Code.

## Смена даты во время запроса к модели

## [[nodiscard]] внутри EXPECT_THROW на MSVC
- **Дата:** 2026-11-07
- **Что случилось:** GoogleTest не подавляет C4834 для вызова [[nodiscard]] внутри
  EXPECT_THROW, хотя результат намеренно не нужен при проверке исключения.
- **Правило:** писать `EXPECT_THROW(static_cast<void>(service.method()), ExceptionType)`;
  предупреждения проекта не отключать.

## Знаки плюс и проценты в QUrlQuery
- **Дата:** 2026-11-07
- **Что случилось:** QUrlQuery сохраняет буквальный `+`, который сервер HTML-форм
  может прочитать как пробел; необработанная последовательность `%2B` тоже меняет смысл.
- **Правило:** перед addQueryItem кодировать пользовательский ввод через
  QUrl::toPercentEncoding. Проверять отправленный URL и однократное декодирование
  формы на запросах с `C++`, `%2B` и `&`, а не только обратное чтение через QUrlQuery.

## CAS черновика после удаления и повторного создания
- **Дата:** 2026-11-24
- **Что случилось:** номер checkpoint может начаться заново после удаления;
  совпадение номера не доказывает, что редактируется тот же черновик.
- **Правило:** сравнивать UUID операции редактирования вместе с номером и
  неизменной исходной редакцией. Повтор старого commit не должен удалять новый
  черновик. Проверять ABA-сценарий через публичный контракт хранилища.

## Холодный Qt-процесс и короткий сетевой timeout теста
- **Дата:** 2026-11-24
- **Что случилось:** интеграционный тест отдельного Debug-клиента использовал
  5 секунд и для холодного запуска с Qt/каталогом, и для ответа сети. Успешные
  запуски занимали 4,73–4,85 с; один прогон не успел при исправных остальных тестах.
- **Правило:** отдельный ограниченный бюджет холодного процесса (10 с) перед
  проверкой auth/get_all; обычные сетевые ожидания не расширять. Ошибки загрузки
  плагинов/QML всё равно проверять по выводу процесса и состоянию соединения.
