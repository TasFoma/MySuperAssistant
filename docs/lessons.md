# Журнал уроков

Грабли, на которые уже наступали: что случилось и как этого избегать.
Это не история работы и не архитектурные решения (они в `docs/decisions.md`).

Формат записи:

```
## <Короткая тема>
- **Дата:** ГГГГ-ММ-ДД
- **Что случилось:** одно-два предложения.
- **Правило:** что делать, чтобы не повторилось.
```

Когда урок становится правилом в `AGENTS.md`, запись отсюда удаляется.

---

## Повторная проверка ожидания не должна читать сокет
- **Дата:** 2026-11-09
- **Что случилось:** помощник ожидания вызывал предикат ещё раз после успеха.
  Предикат чтения уже забрал ответ и при повторном вызове сообщал ложный тайм-аут
  или поглощал следующий ответ.
- **Правило:** предикат с чтением буфера после найденного результата должен
  возвращать сохранённый успех без нового чтения; проверять ответы по request_id.

## Цели Qt видны только там, где их нашли
- **Дата:** 2026-11-04
- **Что случилось:** `find_package(Qt6 ... Quick)` внутри `src/ui/...` — приложение в `src/apps/desktop`
  не видело `Qt6::Quick`, Qt выдавал предупреждение при финализации.
- **Правило:** Qt ищется один раз в корневом `CMakeLists.txt`, в подпапках `find_package(Qt6)` не вызывать.

## Генератор Visual Studio многоконфигурационный
- **Дата:** 2026-10-27
- **Что случилось:** `CMAKE_BUILD_TYPE` в пресете ни на что не влиял, release-пресет собирал Debug.
- **Правило:** конфигурацию задаёт build preset (`"configuration"`), у `ctest` — флаг `-C Debug`.

## Тесты из старой сборки
- **Дата:** 2026-11-04
- **Что случилось:** после правки CMake запустили `ctest` без пересборки — прошёл старый smoke-тест,
  новый код не собирался вовсе.
- **Правило:** после изменений сначала конфигурация и сборка, потом `ctest`; сверить имена тестов в выводе.

## Конфигурация может обновлять уже скачанные зависимости
- **Дата:** 2026-11-06
- **Что случилось:** `FetchContent` остановил конфигурацию без доступа к GitHub:
  шаг обновления PCRE2 выполнялся, хотя исходники уже были скачаны.
- **Правило:** сеть может понадобиться и при повторной конфигурации. При сетевой
  ошибке агент повторяет разрешённую команду с запросом сетевого доступа.
  После правки теста, зарегистрированного через gtest_add_tests, сборка может
  автоматически повторить конфигурацию и снова потребовать сеть; сначала повторить
  разрешённую команду конфигурации с доступом к сети, затем сборку.

## Русский текст в исходниках MSVC
- **Дата:** 2026-10-27
- **Что случилось:** без флага `/utf-8` MSVC выдаёт C4819 на русские комментарии и неверно читает
  русские строковые литералы.
- **Правило:** `/utf-8` задан в `cmake/Warnings.cmake`; не убирать.

## Длина строки в символах, а не байтах
- **Дата:** 2026-10-27
- **Что случилось:** пороги вида «заголовок не короче 3 символов» считались через `size()` — для русского
  текста в UTF-8 это байты, одно слово из 3 букв давало 6.
- **Правило:** длину текста для пользователя считать в символах (`charCount` из `Utf8Text`).

## Личные пресеты не видны агенту
- **Дата:** 2026-10-27
- **Что случилось:** агент предлагал пресет `windows-debug`, потому что `CMakeUserPresets.json`
  в `.gitignore` и он его не видел.
- **Правило:** работать с пресетами `windows-debug-local` / `windows-release-local`
  (шаблон — `CMakeUserPresets.json.example`).

## Смена даты во время запроса к модели
- **Дата:** 2026-11-06
- **Что случилось:** проверка срока ожидания до вызова LLM не учитывала, что ответ
  может прийти после полуночи. Это позволяло записать ответ на уже истёкший опрос.
- **Правило:** перед выполнением действия после долгого внешнего вызова повторно
  проверять временное состояние; переход даты проверять с управляемыми часами.

## [[nodiscard]] внутри EXPECT_THROW на MSVC
- **Дата:** 2026-11-07
- **Что случилось:** GoogleTest не подавляет C4834 для вызова [[nodiscard]] внутри
  EXPECT_THROW, хотя результат намеренно не нужен при проверке исключения.
- **Правило:** писать `EXPECT_THROW(static_cast<void>(service.method()), ExceptionType)`;
  предупреждения проекта не отключать.

## Знаки плюс и проценты в QUrlQuery
- **Дата:** 2026-11-07
- **Что случилось:** QUrlQuery сохраняет буквальный `+`, который сервер HTML-форм
  может прочитать как пробел; необработанная последовательность `%2B` тоже меняет смысл.
- **Правило:** перед addQueryItem кодировать пользовательский ввод через
  QUrl::toPercentEncoding. Проверять отправленный URL и однократное декодирование
  формы на запросах с `C++`, `%2B` и `&`, а не только обратное чтение через QUrlQuery.
